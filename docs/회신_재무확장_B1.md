# 회신 — 재무 계정 확장 완료 (B-1)

> **읽는 주체: 시야트레이더**
> 핸드오프(`docs/핸드오프_재무확장.md`) §5에 대한 회신. 요구한 4종=6컬럼을 `financials`에 확장 수집했다.
> 이 문서를 근거로 Piotroski F-score·총이익성 **조작적 정의를 확정**하면 된다.
> 시야는 **원자료만** 채웠다(비율/팩터 미산출). 팩터 계산은 시야트레이더 몫이다.

---

## 0. 결론

요구한 4종(6컬럼)을 `financials` 테이블에 **연간(FY) + 분기(Q1~Q3) 공용**으로 확장했다. **연간분은 재수집 완료**(전 종목), **분기분은 2026-08-15 이후 재수집 예정**(2026 반기 마감 후). CFO 커버리지 99.7%로 F-score의 발생액·CFO 게이트가 온전히 성립한다.

---

## 1. 데이터 위치·읽는 법 (§5-①)

- **테이블**: `financials` (기존 그대로. 신규 테이블 없음)
- **단위**: 전부 **백만원** (기존 컬럼과 동일)
- **연간/분기 구분**: `fiscal_quarter` — `'FY'`=연간, `'Q1'/'Q2'/'Q3'`=분기
- **무결성**: 외래키 없음(Siya 관례). 종목 조인은 앱 레이어에서.

추가된 6컬럼:

| 컬럼 | 계정 | 용도 (핸드오프 매핑) |
|---|---|---|
| `cost_of_sales` | 매출원가 | 매출총이익 재현·검산용 |
| `gross_profit` | 매출총이익 | **총이익성**(GP/총자산) + F ⑧(매출총이익률 개선) |
| `cash_and_equiv` | 현금및현금성자산 | **EV/EBIT**의 순부채(총부채−현금) |
| `current_assets` | 유동자산 | F ⑥(유동비율 개선) |
| `current_liabilities` | 유동부채 | F ⑥(유동비율 개선) |
| `cfo` | 영업활동현금흐름 | F ②(CFO>0) + ④(발생액: CFO>ROA) |

---

## 2. 커버리지 (§5-②)

**연간 FY 7,603행 기준** (종목 × 연도, 2023~2025 재수집 완료):

| 계정 | 채운 행 | 비율 |
|---|---|---|
| `cfo` | 7,583 | **99.7%** |
| `cash_and_equiv` | 7,500 | 98.6% |
| `current_assets` | 7,436 | 97.8% |
| `current_liabilities` | 7,389 | 97.2% |
| `gross_profit` | 6,857 | 90.2% |
| `cost_of_sales` | 6,763 | 89.0% |

**핵심**: CFO는 현금흐름표 미제출 종목이 사실상 없다(금융 포함 99.7%). 미충족분은 전부 업종 특성 NULL(아래 §5).

**분기 커버리지** (2026-08-20 재수집 완료, Q1~Q3 11,679행 기준): cfo 60.1%(7,022) · 유동자산 58.5%(6,837) · 매출총이익 54.7%(6,387). 2026 Q2 신규 2,540행 포함(2025 Q2 2,592와 나란함).

> ⚠ **분기 비율은 연간(99.7%)보다 낮게 보이지만 정상이다.** 분모(11,679행)에 "제출되지 않은 분기"가 섮여 있다. 많은 중소형주가 분기보고서(Q1·Q3)를 생략하고 반기·연간만 제출하므로, 조회 대상 분기셋 전체를 분모로 잡으면 애초에 존재하지 않는 조합까지 포함돼 분모가 부풀다. 계정 간 서열(cfo > 유동자산 > 매출총이익)이 연간과 동일한 것이 핵심 — 업종 특성이 분기에도 그대로 재현됐다는 뜻이다. **분기 팩터를 쓸 때는 "행이 없음"과 "행은 있으나 계정이 NULL"을 구분**해야 한다(전자=미제출, 후자=업종 부적합).

## 3. 매출총이익 산출 방식 (§5-④)

- **`ifrs-full_GrossProfit` 직접 계정 우선 → 없으면 `revenue − cost_of_sales` 계산 폴백.**
- 실측상(28종목 샘플, 전종목 재수집) **보유 종목은 전부 직접 계정**(계산 폴백 발동 0건).
- `cost_of_sales`도 별도 저장했으니, 시야트레이더가 직접 검산하거나 다른 마진 지표를 만들 때 쓸 수 있다.

## 4. 예외 처리 (§5-③)

- **OFS(개별재무제표)**: 연결 미제출 단일법인. 기존 추출 로직 그대로 6계정 뽑힘(지배주주 폴백과 독립적으로 동작).
- **SPAC / 신규상장 / 폐지 임박 / 부실 소형주**: DART에 추출 가능한 재무 자체가 없어 **행이 없거나 6컬럼 NULL**(연간 재수집에서 158종목 skip — owners 재수집과 동일 꼬리). 이들은 어차피 팩터 유니버스 대상이 아님.
- **우선주(삼성전자우 005935, 현대차2우B 005387)**: `daily_update`가 매일 보통주에서 6컬럼을 복사. 보통주와 동일 재무를 갖는다.
- **비12월 결산**: 확장 계정은 원자료라 결산월과 무관(TTM 게이트 같은 정렬 이슈 없음).

## 5. 예상과 달랐던 점 / 남은 이슈 (§5-⑤)

- **CFO 커버리지가 예상보다 좋다** — 금융(은행·증권·보험) 포함 99.7%. 발생액·CFO 게이트를 전 종목에 적용 가능.
- **모든 NULL이 "결측"이 아니라 "팩터 부적합" 신호다.** 빠진 자리는 전부 금융·순수서비스(NAVER·카카오 등)로, 매출원가·유동/비유동 구분·표준 현금성자산 계정이 원래 없는 업종이다. NULL 비율이 `매출총이익 > 유동구분 > 현금성 > CFO` 순으로 커지는 것도 업종 특성과 정확히 일치.
- **남은 이슈**:
  1. 분기 6컬럼은 2026-08-15 이후 채워짐(현재 연간만 완료).
  2. 연간 재수집 오류 2종목(upsert 실패) — `cfo` NULL로 남아 다음 재수집 시 self-heal. 극소수라 무시 가능.

## 6. 팩터 계산 시 반드시 지킬 것 (시야트레이더 조작적 정의용)

시야가 원자료만 채웠으므로, 아래 규칙은 **시야트레이더가 팩터를 산출할 때** 지켜야 한다.

1. **분기행은 누적(cumulative) 기준이다.** Q1=3개월, Q2=6개월 누적, Q3=9개월 누적(DART `thstrm_add_amount`). 따라서:
   - **TTM 발생액/CFO**: `TTM CFO = FY(전년) − 전년 동기 누적 + 당해 동기 누적`. (기존 TTM 순이익 공식과 동일 구조 — `ttm_earnings` 계산 로직 참고)
   - 분기 개별값이 필요하면 인접 분기 누적을 차감해서 3개월치를 복원.
2. **CFO 음수는 그대로 저장돼 있다.** 영업현금 유출(적자·운전자본 악화)을 의미. F ②(CFO>0)는 `cfo > 0` 여부로, ④(발생액)는 `CFO > 순이익`(또는 CFO/자산 > ROA) 부호로 판정.
3. **NULL 처리 정책이 필요하다.** `gross_profit`/`current_assets`/`current_liabilities`가 NULL인 종목(금융·서비스)은 총이익성·유동비율·F ⑥⑧이 **정의 불가**다. 유니버스에서 제외하거나, F-score를 "적용 가능 항목만으로 부분 채점 후 정규화" 하는 규칙을 정해야 한다. NULL을 0으로 대입하면 안 된다(0점과 정의불가는 다름).
4. **매출총이익률(F ⑧)**: `gross_profit / revenue`. 총이익성(Novy-Marx): `gross_profit / total_assets`. 둘 다 `gross_profit` 그대로 사용(이미 산출됨).
5. **유동비율(F ⑥)**: `current_assets / current_liabilities`. 전년 대비 증가 여부.
6. **EV 순부채**: `총부채(total_liabilities) − cash_and_equiv`. (핸드오프 §2 EV/EBIT용)

## 7. F-score 9항목 완성 매핑

핸드오프 §2 참고 기준, 이번 확장으로 **②④⑥⑧이 계산 가능**해졌다:

| 항목 | 계산 근거 | 상태 |
|---|---|---|
| ① ROA>0 | net_income / total_assets | 기존 가능 |
| ② CFO>0 | **`cfo`** | **이번 확장** |
| ③ ΔROA>0 | 연도별 ROA 비교 | 기존 가능 |
| ④ 발생액 (CFO>ROA) | **`cfo`** vs net_income | **이번 확장** |
| ⑤ Δ레버리지 | total_liabilities 기반 근사 | 근사 가능 |
| ⑥ Δ유동비율 | **`current_assets`/`current_liabilities`** | **이번 확장** |
| ⑦ 신주 미발행 | 발행주식수 이력 | 근사 가능 |
| ⑧ Δ매출총이익률 | **`gross_profit`/`revenue`** | **이번 확장** |
| ⑨ Δ자산회전 | revenue / total_assets | 기존 가능 |

→ **정통 9항목이 전부 성립.** ⑤⑦은 근사(기존 데이터), 나머지 7항목은 직접 계산 가능.

## 8. 범위 밖 (B-2로 분리, 이번 미포함)

핸드오프 §3-4 그대로 — 감사의견·관리종목 배제 게이트는 별도 소스(DART 감사보고서 등)라 이번에 넣지 않았다. 필요하면 B-2로 별도 요청.
