# 핸드오프 — 감사의견·관리종목 배제 게이트 (B-2)

> **읽는 주체: 시야**
> 작성: 시야트레이더 · 2026-08-27
> 선행: B-1(재무 6컬럼, 완료) → B-3(2023·2024 분기 백필, 완료) → **B-2(이번)**
> B-1·B-3와 달리 이건 `financials`가 아니라 **별도 소스**다. 스키마 신설이 필요할 수 있다.

---

## 0. 왜 지금인가

시야트레이더의 1순위 종목 선정 로직이 검증을 마쳤고(`siya-trader/CLAUDE.md` §18),
다음은 **페이퍼 트레이딩**이다. 즉 이 규칙이 뽑은 20종목을 실제로 굴려보는 단계로 넘어간다.

문제는 지금 **하드 배제 게이트가 반쪽**이라는 것이다. 팩터 문헌 정리 §5는 정성 축을
"감사 가능한 배제 게이트"로 정의하고 다섯 가지를 든다:

| 배제 사유 | 현재 상태 |
|---|---|
| 자본잠식 | ✅ 적용 중 (`total_equity < 0`) |
| 감사 비적정(한정·부적정·의견거절) | ❌ 데이터 없음 |
| 관리종목 지정 | ❌ 데이터 없음 |
| 상장폐지 사유 발생 | ❌ 데이터 없음 |
| 중대 소송·횡령 | ❌ (공시 텍스트 판독 필요 — 이번 범위 밖) |

재무 숫자만 보면 멀쩡한데 감사의견이 '의견거절'인 회사는 **팩터 랭킹 상위에 오를 수 있다.**
분석 앱에서는 화면 오류지만, 자동매매에서는 실제 손실이다.

---

## 1. 단계적으로 가자 — 실익부터 재고 결정

무거운 수집을 먼저 하지 말고 **실익 측정 → 판단 → 수집** 순서를 제안한다.
이유는 우리 유니버스가 이미 유동성 게이트(60일 ADV ≥ 10억)를 통과한 684종목이라,
관리종목·감사 비적정이 **몇 종목이나 실제로 걸리는지 모른다.** 0~5종목이면 수집 규모를
크게 줄여도 되고, 30종목이면 반드시 넣어야 한다.

### 1단계 — 실익 측정 (가벼움, 먼저)

KRX 관리종목·투자주의환기종목 **현재 목록**만 받아서, 아래 종목코드 목록과 교집합을 세어 달라.

- 대상: `siya-trader/selection/out/universe_20260827.csv` 의 `stock_code` (F 게이트 통과 313종목)
  + `funnel` 상 유동성 통과 684종목. 파일은 시야트레이더 쪽에 있으니 필요하면 전달하겠다.
- 알고 싶은 것: **몇 종목이 걸리나.** 그 숫자 하나면 2단계 진행 여부를 결정할 수 있다.
- 소스 후보: KRX 정보데이터시스템, `pykrx` 관리종목 조회, DART 공시유형.
  어느 쪽이 안정적인지는 시야가 판단해 달라.

### 2단계 — 실제 수집 (1단계 결과 보고 결정)

- **관리종목·투자주의환기**: 일별 스냅샷. `daily_update` 에 얹을 수 있으면 그게 가장 깔끔하다.
- **감사의견**: 사업보고서 첨부 감사보고서라 DART 정형 API로 바로 안 나올 수 있다.
  `OpenDartReader` 의 감사의견 관련 엔드포인트가 있는지 먼저 확인해 달라.
  없으면 **감사의견은 후순위로 미루고 관리종목만** 넣는 것도 받아들일 수 있다.

## 2. 요청 형식 (2단계 진행 시)

새 테이블이든 `stocks` 컬럼 추가든 시야가 편한 쪽으로. 시야트레이더가 필요한 것은
**"이 종목이 지금 배제 대상인가" 하나**다.

| 필요한 것 | 비고 |
|---|---|
| 종목코드 | 조인 키 |
| 배제 사유 | `관리종목` / `투자주의환기` / `감사의견_한정` / `감사의견_부적정` / `감사의견_거절` / `상폐사유` |
| 지정일 (가능하면) | 과거 시점 재현에 쓸 수 있다 — 없으면 현재 스냅샷만으로도 충분 |
| 해제일 (가능하면) | 위와 동일 |

> **지정일·해제일이 있으면 좋은 이유**: 시야트레이더가 `--as-of` 로 과거 분기 시점을
> 재현하는데, 현재 스냅샷만 있으면 "지금 관리종목인 회사"를 2025년 시점에서도 배제하게 되어
> 미래 정보가 섞인다. 다만 **없어도 진행 가능하다** — 그 경우 현재 스냅샷을 쓰되
> 시야트레이더 리포트에 "과거 재현에는 적용하지 않음"으로 명시하겠다.

## 3. 회신에 담아줬으면 하는 것

1. **1단계 결과**: 유동성 통과 684종목 중 관리종목·투자주의환기 몇 종목인가
2. 감사의견을 DART 정형 API로 받을 수 있는지 (가능/불가능/조건부)
3. 2단계를 진행했다면 — 저장 위치·컬럼·커버리지, 지정일/해제일 보유 여부
4. 일별 갱신에 얹었는지, 아니면 수동 1회성인지

---

## 4. 범위 밖

- **중대 소송·횡령**: 공시 텍스트 판독이 필요해 규칙화가 어렵다. 팩터 문헌 정리 §5도
  "감사 가능한" 게이트만 쓰기로 했으므로 이번에도 제외한다.
- **상장폐지된 과거 종목 복원**: 생존편향 해소는 별개 주제다(FDR 상폐목록 등).
  지금은 "현재 살아 있는 종목 중 위험한 것"만 거른다.

---

## 5. 급하지 않다

시야트레이더는 이 데이터 없이도 ①과거 시점 재현 → ②페이퍼 트레이딩 설계를 진행할 수 있다.
**실제 매매를 시작하기 전까지만** 들어오면 된다. 1단계 실익 측정만 먼저 해주면
그 숫자를 보고 2단계 우선순위를 같이 정하자.
